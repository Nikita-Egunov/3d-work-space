# 3D Work Space

![Demo](https://Nikita-Egunov.github.io/3d-work-space/)

3D Work Space is a 3D visualization of a workspace environment created using React, Three.js, and React-Three-Fiber. This project showcases a virtual room with various objects like a table, laptop, monitor, bookshelf, and more.

## Features

- 3D room visualization
- Interactive controls with orbit controls
- Various 3D models including:
  - Table
  - Laptop
  - Ultra-wide monitor
  - Bookshelf with books
  - Chair
  - Plants
  - Walls

## Technologies Used

- React
- Three.js
- React-Three-Fiber
- React-Three-Drei
- TypeScript
- Vite

## Getting Started

### Prerequisites

Make sure you have Node.js and npm installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Nikita-Egunov/3d-work-space.git
   cd 3d-work-space
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:3000` to see the 3D workspace in action.

### Building for Production

To create a production build, run:
```bash
npm run build
```

### Deployment

The project is set up to deploy to GitHub Pages. To deploy, run:
```bash
npm run deploy
```

## Project Structure

- `src/`: Main source code directory
  - `app/`: Application root components
  - `features/`: Feature-specific components
  - `pages/`: Page components
  - `shared/`: Shared components, hooks, and utilities
  - `styles/`: Global styles
- `public/`: Static assets
- `models/`: 3D model files
